FORMULA BREAKDOWN
Forecast equation
ŷ(t+h) = ℓ(t) + h·b(t) + s(t+h-m)
Combines level, trend, and seasonal component to project h steps ahead. m = season length (7 days).
Level update ℓ(t)
ℓ(t) = α(y(t)−s(t−m)) + (1−α)(ℓ(t−1)+b(t−1))
High α → model reacts fast to recent data. Low α → smoother, less reactive baseline.
Trend update b(t)
b(t) = β(ℓ(t)−ℓ(t−1)) + (1−β)·b(t−1)
High β → trend direction updates quickly. Low β → trend is more stable and inertial.
Seasonal factor s(t)
s(t) = γ(y(t)−ℓ(t−1)−b(t−1)) + (1−γ)·s(t−m)
Captures repeating weekly / annual cycles. High γ → seasonal pattern updates rapidly.
Initialisation
ℓ(0) = mean(y[1..m])
b(0) = (mean(y[m+1..2m]) − mean(y[1..m])) / m
Level and trend seeded from first two seasons. Seasonal factors normalised to sum to zero.
Parameter tuning
Optimal α, β, γ found by minimising Sum of Squared Errors (SSE) via L-BFGS-B optimisation:
argmin Σ(y(t) − ŷ(t))²

MODEL SELECTION GUIDE
Moving Average
MA(n) = Σy(t−i) / n
New products, <30 days data. No trend or seasonality.
Use when: history < 30d
Linear Regression (trend)
ŷ = β₀ + β₁t
Steady upward/downward trend, no seasonality pattern.
Use when: no seasonality
Holt-Winters (Triple ETS)
Level + Trend + Seasonal
Seasonal goods, ≥2 full cycles of history. Best for most SKUs.
Use when: strong seasonality
ARIMA / SARIMA
ARIMA(p,d,q)(P,D,Q)m
Stable stationary series, autocorrelation structure. Needs differencing.
Use when: autocorrelated
XGBoost / ML
External regressors + lag features
Promotions, weather, events affect demand. Needs feature engineering.
Use when: external drivers
Ensemble (weighted avg)
ŷ_e = Σ wᵢ·ŷᵢ / Σwᵢ
When no single model dominates. Weights inversely proportional to MAPE on validation set.
Best MAPE: 9.8%

ANOMALY FORMULA
Z-score anomaly condition
Flag if: |x(t) − μ| > K · σ
μ = rolling 30-day mean demand. σ = rolling standard deviation. K = sensitivity (default 2.5). Values beyond K·σ from mean are flagged for manual review.
Anomaly trigger categories
Demand spike Sudden high sales — possible data entry error or promotional event not recorded
Demand drop Zero or near-zero demand for normally active SKU — possible system outage or receiving issue
Large adjustment Manual stock adjustment > 3σ — requires supervisor approval in workflow

REORDER FORMULAS
Safety stock (Z-score method)
SS = Z × σ_d × √(Lead Time)
σ_d = std dev of daily demand. Z = 1.65 at 95% service level.
Safety stock (min-max method)
SS = (MaxDS × MaxLT) − (AvgDS × AvgLT)
Conservative approach. Used as cross-check against Z-score method.
Reorder point
ROP = (AvgDS × AvgLT) + SS
Triggers a purchase order when stock falls to this level. Accounts for demand during lead time.
Economic Order Quantity
EOQ = √(2 × D × S / H)
D = annual demand, S = order cost, H = holding cost per unit per year.
Days of inventory cover
DoC = Current Stock / Avg Daily Sales
How many days before stockout at current consumption rate, ignoring incoming orders.
Urgency classification
Critical stock < SS
Warning SS ≤ stock < ROP
Optimal stock ≥ ROP
FORECAST ERROR METRIC DEFINITIONS
MAPE — Mean Absolute % Error
MAPE = (1/n) Σ |y−ŷ| / y × 100
Most interpretable. Expressed as %. Problem: undefined when y=0. Target: <15% for IMS.
<10% Excellent 10–15% Good >20% Poor
MAE — Mean Absolute Error
MAE = (1/n) Σ |y(t) − ŷ(t)|
In same units as demand (units/day). Not sensitive to outliers. Good for comparing models on same scale.
RMSE — Root Mean Squared Error
RMSE = √( (1/n) Σ (y−ŷ)² )
Penalises large errors more than MAE. Good for safety-critical inventory where spikes are costly.
WAPE — Weighted Absolute % Error
WAPE = Σ|y−ŷ| / Σy × 100
Handles zero-demand periods better than MAPE. Used in retail and distribution at aggregate level.
Bias — Mean Error
Bias = (1/n) Σ (ŷ(t) − y(t))
Positive bias = systematic over-forecast (overstock risk). Negative = under-forecast (stockout risk). Target: near 0.
Tracking signal
TS = Σ(y−ŷ) / MAD
MAD = Mean Absolute Deviation. |TS| > 4 signals systematic forecast bias needing model recalibration.

FORECASTING PIPELINE — END TO END
STEP 1 — Data ingestion
Raw demand extraction
Pull STOCK_OUT + SALE_DISPATCH movements from inventory_movements table. Exclude cancellations, returns, damages.
STEP 2 — Preprocessing
Clean and aggregate
Aggregate to daily totals per SKU × warehouse. Fill zero-demand days. Cap outliers via IQR (1.5× IQR rule). Normalise.
STEP 3 — Model selection
Auto-fit per SKU
Evaluate history length, CoV, seasonality score (ACF). Select best model from MA → Regression → HW → ARIMA → Ensemble.
STEP 4 — Training
Fit on 80% history
Train on 80% of historical data. Validate on 20% holdout. Optimise α, β, γ via SSE minimisation (L-BFGS-B).
STEP 5 — Forecast generation
7 / 14 / 30 / 90 day
Generate point forecasts + 80% / 95% confidence intervals via Monte Carlo simulation (1000 draws). Store in forecasts table.
STEP 6 — Reorder trigger
Auto PO suggestion
Compute SS, ROP, EOQ per SKU. Compare current stock vs ROP. Classify urgency. Surface in reorder dashboard. Trigger PO draft.
